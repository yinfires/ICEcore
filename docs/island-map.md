# 岛屿地图实现与验证

用途：维护 Xaero 地图采集、区域编辑、灰雾、共享解锁及资源包制作链路。修改这些行为前读取本文。

## 入口与依赖

- `worldmap.MapDefinition` 保存维度、底图范围、atlas ID 和区域；`MapService` 负责 OP2 编辑、绑定采样、配置事务、命令及同步；`MapSavedData` 在主世界 `data/icecore_map.dat` 保存全服共享解锁。
- `MapNetwork` 使用独立 `icecore:world_map` 通道；定义与解锁带修订号，过期编辑拒绝。服务端请求限频100毫秒；大编辑按24KB分片，最多42片/1MB，30秒超时；普通玩家不能写定义。服务端不依赖 Xaero 或客户端类初始化。
- 客户端 `worldmap.client.MapClient` 仅 Dist.CLIENT 自动注册 M、资源刷新和断线事件；`IslandMapScreen` 管理编辑和显示，`XaeroEditorMap` 通过 Screen 虚方法调用真实 GuiMap 渲染与缩放，`XaeroEditorAccessor` 读取原生相机；`MapAtlas` 仅负责玩家瓦片，`XaeroSnapshot` 复用原生采集/导出，`MapFog` 与 `MapViewport` 为独立纯逻辑。
- 固定客户端 Xaero 世界地图1.47.0；目标客户端已安装的 `[Xaero的世界地图] xaeroworldmap-forge-1.20.1-1.47.0.jar` 与下载参考JAR SHA-256一致：`88c6d844163c95a94d92bc6d87d9011cc840bd6207c3099a81b113d4450a3f6b`。其jarjar内嵌XaeroLib1.7.3，不另装。两个JAR只在本地libs作compileOnly参考，不打进ICEcore。
- 参考1.3.1模组的 `CityMapScreen extends xaero.map.gui.GuiMap`，`CityAtlas`读取manifest及预制分级PNG；不复制其世界资源或1.21.1 NeoForge接口。

## 定义与编辑

- 世界内容写运行实例 `config/icecore/world_map.json`，无内置示例；初次无定义时全灰。配置与快照均不写进模组资源树。
- 顶层字段：`dimension`、`minX/minZ/maxX/maxZ`（最大值不包含）、`atlas`、`regions`。每区域含 `id`、`binding`、`expansion`、`feather`、`polygons`（多个x/z点数组）及 `runs`（x/z/长度三元组构成的精确方块投影）。最大128区域、单轴16384格、每轮廓512点、总复杂度180000、序列化UTF-8最多750000字节，确保完整服务端快照不超网络包限额。
- `/icecore map editor` OP2打开无迷雾的 Xaero 原生已记录地图；无需先生成快照，浏览不受底图导出范围或解锁限制。原生未记录地形仍不可凭空显示。工具区分为四列主操作页和共边工具页，所有按钮、输入框和搜索列表项都有原生 Tooltip 双语说明；按圈选、有效顶点、来源、保存状态与生成状态启用。新建直接进入圈选；选择已有区域后可添加轮廓，也可选择已有轮廓拖动黄色顶点修改。左键加点或拖顶点、右键拖地图、滚轮缩放；完成至少3个非退化顶点后原子替换草稿，取消保留原轮廓。MapEditorRules 只将导出范围扩大至手绘轮廓最外沿（手绘不再额外外扩），超过16384格上限拒绝且保留原稿。绑定前先保存全部编辑。
- `island:<name>` 使用IslandManager已有捕获数据，隐藏岛也可计算轮廓；`region:<name>`只读取已加载区块，不主动生成/加载世界。按非空气列压缩行段，保留任何大小的独立岛体；圈选和绑定投影可以共存。绑定刷新替换旧绑定投影，圈选轮廓保留。移除先删除最后一个手绘轮廓，没有手绘轮廓时移除绑定投影。
- 服务端采样每tick最多8192次方块查询且2ms预算、120秒超时；最大16777216列/268435456体积。按快照或真实已加载区块查询，编码行段与写JSON走单后台线程；提交使用临时文件原子替换，不支持原子移动时同目录替换。出错保留旧定义。
- 锁定/解锁命令 `/icecore map lock <id>`、`unlock <id>`，重读配置 `/icecore map reload`；默认OP2。任务命令奖励可调用上述命令。公共Java接口 `MapService.setUnlocked(id, boolean)` 必须在服务端线程执行；未知ID返回false，重复操作幂等。地图解锁不影响岛屿真实显现。

## 相邻区域与预览

- `MapPolygonEditor`使用原坐标多边形表达共边，不新增配置格式。普通点编辑保持6 GUI像素顶点/边线吸附，Alt临时禁用；共边选择使用独立边线投影判定，不受附近顶点优先吸附影响。重叠候选距离相差不超过1 GUI像素时通过“区域ID / 轮廓N”列表明确选择源轮廓，选定起点后终点限定同一源轮廓。
- `MapEditMode`明确区分逐点圈选与选共边。主工具新建/圈选默认逐点；共边工具页分别提供“沿边圈选”“逐点圈选”按钮并标出当前/切换。选边只高亮青色候选边、白色空心起点和橙色预览路径，`MapEditorSketch`不绘制任何黄色顶点，鼠标跟随黄线也隐藏；采用后保持选边模式，只有主动切回逐点才恢复黄点。已采用路径青色显示，完成/取消清除临时高亮。
- 选起点、终点后可反转路径再采用，落在线段中的端点同时插入源轮廓。采用先在candidate校验再替换working，最近一次采用保留单份撤销快照，撤销依次清除终点、起点、最近采用路径及插点；切回逐点后使用原末点撤销，不保留无界历史。完成时检查重复点、零面积、自相交及原复杂度/尺寸限制，联动轮廓全部通过后整体替换draft；取消不写任何轮廓。`validateChanged`用旧轮廓HashSet判别改动，避免大量碎片的二次方列表比对。绑定投影可显示/命中但不能直接改顶点。
- 默认联动全部同坐标共享顶点，可关闭；拖点先联动再补插吸附端点，避免源轮廓重复点。悬停逐项显示区域ID与锁定状态，单区点击切换、多区重叠用原生搜索列表选择。右键拖图、方向键移动、滚轮缩放在两种模式都有效；视野变化清除过时候选边。所有模式/步骤/用途维护中英文原生Tooltip。
- `MapUnlockPreviewScreen`拷贝定义和本地解锁集合，通过选择切换单区、全选/清空查看最终MapFog；不调用网络写请求或服务端状态。预览覆盖真实Xaero底图，返回保留父编辑器相机及草稿。距离索引仅选区变化时重建，遮罩按当前视窗最多2048²像素后台采样，视野变化最多每100ms请求一次且只有单任务；旧图按世界坐标复用、未覆盖处全灰。generation取消与关闭/断线/维度/权限/重载清理继续生效。
- 玩家仅新增解锁时保留旧atlas，后台准备视窗瓦片后`MapRevealTransition`执行300ms smoothstep合成；未就绪重置计时。新旧各24纹理，全部atlas共用4解码名额，视窗显示层级最多24瓦片，合成前flush，完成释放旧图并恢复48常驻上限。连续解锁丢弃旧候选，锁定/定义变化安全立即替换；同步只按新边界clamp，不主动重新居中。

## 瓦片采集与发布

- 开发者先用Xaero记录范围，选择地表图层，再生成。ICEcore与Xaero原生地图入口独立，在控制设置分别绑定按键，ICEcore默认M；删除ScreenEvent.Opening替换，不再接管原生GuiMap。编辑器内部持有原生 GuiMap，不通过再次打开采集界面切换。调用真实Screen虚方法，生产SRG方法签名已核对；原生UI/跟随相机状态只在底图渲染期间临时调整并finally恢复，不转发原生标记/传送输入。
- 真实调用链：`WorldMapSession → MapProcessor → MapSaveLoad.requestLoad`加载已有地图数据，逐chunk核对`MapTile.isLoaded`（原生磁盘加载只置isLoaded，不置wasWrittenOnce），`WorldMap.mapRunner.addTask(MapRunnerTask)`串行化地图处理后在Minecraft线程调用`PNGExporter.export`。沿用其原生GL/缓存绘制，不自行采样方块颜色。
- 每次最多导出512×512方块一张。MapCapturePlan后台对全部定义区域（含尚未解锁区域）的最终可见几何与chunk矩形相交生成最多约1025²位的需求位图；手绘柔边向内不增加外侧采集，绑定仅按投影外扩扩大几何；仅这些chunk要求真实采集。尚未定义任何轮廓时保留先按指定矩形导出的原有流程，此时整个矩形都需要采集；已有轮廓时，矩形灰雾角落和区域间全灰空隙不阻塞，空瓦片后台生成灰图，不读取Xaero缓存；其它瓦片导出后将非必需chunk覆盖中性灰，避免下采样黑边。必需区块缺失、非地表、缓存超时、导出失败、尺寸非1:1均拒绝发布。原生MapRunner串行化读取tile.isLoaded与PNG导出；首个真正缺失chunk红标并提示坐标，旧资源保留，不自动加载远处世界。
- 每tile完成后100ms间隔；实际原生导出使用GL并会执行同步缓存I/O，此成本限制在开发者显式生成期间，尚需实机测单tile耗时。CPU图像整理、分级缩放和打包使用后台线程。采集有加载30秒超时，MapRunner等待30秒超时释放。
- 中间/正式资源位于 `config/icecore/world_map_atlases/atlas_<uuid>/`，分级0..5，512px瓦片、固定世界坐标索引，纹理目录 `assets/icecore/world_map/<atlas>/<level>/<x>_<z>.png`。边缘瓦片按实际范围处理，负坐标用floorDiv。
- 全部成功才生成独立 `resourcepacks/ICEcore-atlas_<uuid>.zip`，启用并重载后提交新定义。旧定义与旧资源包不删除；失败/取消不提交atlas ID。新包供其他客户端或服务器资源包分发；每名玩家必须启用相同atlas资源。取消时可能留下可清理的未发布中间资源。
- 资源包发布额外核对repository已选中候选包，reload后资源管理器能查到首张实际瓦片，再提交atlas ID；失败恢复旧选择。atlas=unpublished时不请求虚构瓦片，给出“快照尚未生成成功”说明；只有已发布atlas确有瓦片缺失才报缺资源。
- 首次可直接在原生已采集底图圈选，再明确生成玩家地图快照。编辑与生成互斥；编辑器底图始终无迷雾，解锁组合通过独立预览页查看。发布时保留当前atlas包加候选包，最多同时保留两套地图包启用，避免服务端拒绝提交时旧底图丢失。

## 表现与性能

- 2026-11-01用户明确更新规则：手绘轮廓就是迷雾最外沿，边界及外侧全灰，向内按feather（默认64格）smoothstep消散。`expansion`保留JSON兼容，仅用于绑定投影的外扩（界面改名“绑定外扩”），不会扩大手绘圈选。绑定从外扩投影最外沿向内柔化；已锁核心扣除已解锁实际并集后受保护，外扩不揭开剩余锁定地形。旧快照已含更大支持范围，可继续用；只有扩大绑定投影、底图或未采集范围时才需明确重生成快照。
- `MapFog`后台构建已解锁几何Area并集、扣除保护差集并裁到atlas；只索引并集真实外缘，共边与重叠内部线不参与迷雾。精确AABB边层次树进行奇偶命中和最近线段欧氏距离查询，alpha=255×(1−smoothstep(内侧距离/柔边))；废除“核心直接alpha=0”和向外距离场相乘，避免截图中的硬切边。任一已解锁实际轮廓决定可见范围优先，但外缘仍渐变，不再被强制完全透明。
- 每区域不同柔边通过组件Profile AABB树取命中区域最大可见度；Profile同时验证原区域（含孔洞）命中，洞内独立区域不会继承外圈的柔边；小岛/独立碎片的宽高限制柔边不超过短边一半，保留1格岛内部，不按面积筛除。绑定投影先归一化行段并保留洞，再处理外扩；闭合Area并集消除行内接缝与正反绕序差异。采样不使用粗网格，所以斜边、负坐标及窄片区没有栅格泄漏；纯几何构建和图像采样均在单后台执行器，渲染不计算距离。
- 性能样本：20000个独立RLE碎片、262144次最终alpha采样，耗时记录`tmp/map-inspect/inward-performance.txt`；这是非客户端CPU样本，不能证明游戏帧耗时。索引构建按行/轮廓/树节点检查取消，Area布尔运算在后台完成；采样不分配对象、不扫描世界、不读磁盘，Profile树避免逐像素扫描所有碎片。渲染仍只遍历视窗缓存纹理；编辑选边只在鼠标移动/点击时扫描多边形，非候选边不创建Point，单次最多原定义180000顶点。
- 页面固定北向上，缩小极限为已解锁轮廓/扩展绑定投影的包围盒，留白6%，不再给手绘额外加外扩/柔边；无区域禁止平移缩放。最多48张常驻512px纹理及全局4解码任务。关闭/重载/断线/维度/权限清理与候选generation丢弃保留。
- 自己头像16×16 GUI像素，含帽子层，外加1 GUI像素白框，总18×18；不显示名字/坐标、不吸附边缘、不扩大视野；在灰雾也显示，越界裁剪。

## 验证与边界

- `MapFogInwardTest`覆盖手绘不外扩/分数边界、单侧锁定向内渐变、全解锁并集共边无缝、不同柔边、投影外扩保护与交叠优先、RLE洞/洞内独立区域柔边/行接缝/单像素碎片、三角斜边解析距离、选边投影与顶点判定分离、重叠来源显式选择、2万碎片性能样本，生成`tmp/map-inspect/inward-fog-preview.png`。`MapEditorSketchTest`调用实际黄点绘制入口，确认选边及采用后无绘制调用、切回逐点后恢复。合成图与mock渲染验证不能替代首次真实界面验收。

- MapEditorForm独立保存ID/范围/外扩/柔边的原始输入文本；EditBox responder同步文字，init只从form重建，不从旧定义覆盖。应用范围和保存共用事务apply：同时解析范围与参数，验证全部成功后替换草稿；保存直接读取范围，无需先应用。非法输入保留在框内供修正，不修改原稿。仅切换区域、新建、删除或完成轮廓时明确载入相应参数。自己的保存回包匹配pending提交，推进修订号且保留提交后的新文字；快照确认合并新atlas，避免后续保存退回unpublished。待确认时禁止save/bind/snapshot重复提交，10秒后允许重试；其它编辑可继续。外部冲突保持原修订号与草稿，服务端继续拒绝过期提交。
- 首次打开必须禁止嵌入底图反向初始化所属编辑器：XaeroLib1.7.3 ScreenBase.init会对escape调用Screen.init。XaeroEditorMap的GuiMap父/返回参数固定null，由外层编辑器独立管理导航，否则首次Screen.initialized尚为false时递归init注册两套控件，选择返回rebuildWidgets才清空重影。MapEditorLifecycleTest同时核对真实XaeroLib此调用与最终GuiMap构造的两个null，覆盖上轮单次render测试漏掉的生命周期。
- 玩家地图与编辑器均支持方向键平移，圈选期间照常可用；方向含义为视野中心向对应方向移动。窗口激活且没有EditBox焦点时每帧读取4个原生按键状态，240 GUI像素/秒，斜向归一，dt最多50ms；只传相机位移，玩家地图继续受解锁边界clamp，编辑器不受发布范围限制。无按键锁存，松键/失焦即停止；removed清除单调帧时钟，返回第一帧不移动。O(1)、无每帧集合分配/网络/文件操作。输入框方向键保留光标编辑；点击地图或操作按钮后即可继续平移。
- 四个原生EditBox仅addWidget注册输入，不加入Screen的自动renderables，由MapEditorWidgets每帧各调用一次原生render，字段独立scissor/flush且finally清除裁剪；不覆盖原生字体、背景、边框。移除有值字段的hint，含义复用原生Tooltip。Xaero原生底图绘制前后flush并push/pop pose，随后清深度，再绘制编辑工具。真实ModernUI3.12.0.1的MixinEditBox仍接管原生renderWidget与字体；此调用边界测试不能代替实际整合包叠影截图验收。固定4个框，主页面16按钮、工具页面13按钮，渲染不序列化定义或扫描世界，form只在输入/操作/同步时解析和复制。
- `MapEditorLifecycleTest`：真实XaeroLib首次init返回链与嵌入构造空返回目标，60/144帧等速、斜向归一及暂停位移限制。
- `MapCaptureTest`：矩形无关角落排除、未来解锁小岛与柔边完整覆盖、负坐标与chunk边缘、无轮廓时完整矩形导出、真实Xaero磁盘加载标记及最终导出字节码调用、无原生地图Opening替换。
- `MapEditorFormTest`：范围与参数同时保存/序列化重开、连续保存ack、ack期间继续输入、外部冲突/解锁同步、非法输入事务、区域选择和快照atlas保留；`MapEditorWidgetsTest`校验每字段一次原生render及裁剪/flush时序。
